# EAI Suite Guide Inconsistencies

## Scope and Evidence

This report covers only:

- `section_guides/03-2-amd-resource-manager.md`
- `section_guides/04-3-amd-workbench.md`

The comparison used the authenticated Silogen demo interfaces on September 1, 2026 and the linked AMD Enterprise AI `en/latest` documentation. No model, project, user, dataset, secret, API key, storage resource, or workspace was created, changed, or deleted. Existing image assets were not edited.

Status meanings:

- **corrected**: The Markdown statement or navigation was updated.
- **manual check**: The relevant action or screenshot was not safely validated end to end.
- **deployment-specific**: Behavior or naming can vary by installation.
- **role-dependent**: Visibility or available actions depend on the signed-in role or project membership.
- **intentionally unchanged**: The issue is recorded but its text was left unchanged per user instruction.

## Deliberate Exclusion

The guides do not add a replacement inference-metrics section covering inter-token latency, end-to-end latency, request state, concurrency, token counts, KV-cache utilization, replica filtering, or time ranges. The existing Workbench SLO and deployment-timing passage remains unchanged and is marked **intentionally unchanged** above.
